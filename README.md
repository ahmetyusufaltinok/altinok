Kişisel web sitesi: hizmetler, çalıştığım markalar, kariyer ve iletişim.

Tek dosyalık statik site (`index.html`). Harici bağımlılık yok; yalnızca Google Fonts'tan Archivo yazı tipi yüklenir.

## Yayınlama (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
Birkaç dakika sonra site `https://<kullanıcı-adı>.github.io/<repo-adı>/` adresinde yayında olur.
